# Deskmate 2.21.1

- Pemeriksaan pembaruan memiliki jalur cadangan lewat halaman rilis resmi GitHub saat API GitHub gagal. Deskmate tetap memverifikasi SHA-256 sebelum memasang pembaruan.
- Jika checksum tidak tersedia, tombol pembaruan membuka halaman rilis untuk pemasangan manual.

Jika versi lama menampilkan “Couldn’t reach GitHub”, unduh `Deskmate-Setup.exe` dari aset rilis ini dan jalankan untuk memperbarui instalasi. Pengaturan dan data yang ada tetap dipakai.
