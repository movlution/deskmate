# Deskmate 2.22.0

- **Ikon Dock khas Deskmate**: tombol Start, Semua jendela, Tugas, Suruh, dan Rak kini memakai ikon bergambar sendiri yang serasi dengan gaya Deskmate.
- **Tombol Suruh di Dock**: satu tombol untuk membuka obrolan Suruh Deskmate, jendelanya menyatu di slot itu. Atur di Pengaturan › Dock (`dockbar.suruh`).
- **Konversi lebih lengkap**: banyak gambar bisa jadi satu PDF atau satu PDF per berkas, gambar bisa disusun atau dijadikan GIF, dan banyak audio digabung jadi satu MP3.
- **Pengaturan bergambar**: setiap kategori punya ilustrasi sendiri di hub, judul halaman, dan rel samping.
- Kuota Claude Code lebih andal, hook agen koding lebih aman, dan cuaca mencoba lagi lebih cepat saat Wi-Fi belum siap.

Pengaturan dan data yang ada tetap dipakai.
